✦ The Big Picture

On the same day Anthropic handed Claude Mythos Preview to Apple and Goldman Sachs for testing, a handful of people in a private Discord got their hands on it too, through a third-party vendor environment that was never supposed to let them in. The model at the center of the leak is the same one Mozilla just used to find 271 vulnerabilities patched in Firefox 150. One capability. Two hands. The dual-use question stopped being hypothetical this week.

Today's Headlines

Mythos Containment Tested

  • Claude Mythos Leaked Through a Vendor the Day It Was Handed to Apple and Goldman — Anthropic confirmed to the Guardian that it is investigating unauthorized access to Claude Mythos Preview by "a handful" of people in a private online forum. The access came through a third-party contractor environment, on the same day Anthropic formally handed the model to a small testing group including Apple and Goldman Sachs. Bloomberg reports the group hasn't run cybersecurity prompts yet — they're "playing around" — but the UK AI Security Institute warned last week that Mythos is "a step up" in cyber-threat capability, able to carry out multi-step attacks and find IT weaknesses without human intervention on work that would take professionals days. UK AI minister Kanishka Narayan told businesses they "should be worried."
  • Mozilla Used the Same Model to Patch 271 Firefox Vulnerabilities — Firefox CTO Bobby Holley, quoted by Simon Willison, described Mozilla's collaboration with Anthropic on an early version of Claude Mythos Preview as "hopeful": the partnership identified 271 vulnerabilities fixed in Firefox 150. Holley's framing is striking — teams will have to reprioritize, but "defenders finally have a chance to win, decisively." This is the sunny side of the exact same capability that has AISI warning UK businesses.

Pricing Pressure on Coding Agents

  • Is Claude Code About to Cost $100/Month? — On April 22, Anthropic quietly updated its pricing page to move Claude Code off the $20 Pro plan and onto Max plans ($100–$200/month). The Internet Archive caught the change. Anthropic's Head of Growth described it on X as a test affecting "~2% of new prosumer signups," and the visible changes were reverted within hours — while the experiment apparently continued for a sliver of new signups. Simon Willison's criticism is sharp: a single employee tweet was the only official communication. He notes OpenAI's Codex remains on free and $20 tiers, making it the easier recommendation for journalists and students, and he's demanding "a very firm commitment" that Claude Code stays on Pro.
  • GitHub Copilot Tightens Limits, Restricts Opus 4.7 to Pro+ — GitHub paused individual-plan signups, tightened usage limits, restricted Claude Opus 4.7 to the $39/month Pro+ tier, and discontinued previous Opus models. Willison flags the root cause quoted by GitHub: "Long-running, parallelized sessions now regularly consume far more resources than the original plan structure was built to support." Six months ago, heavy LLM users still burned fewer tokens per dollar. The old per-request pricing model broke when individual requests started consuming massive token volumes. The new scheme uses token-based caps on weekly and per-session bases — but it's unclear which of GitHub's 75+ Copilot-branded offerings (CLI, cloud agent, code review, IDE integrations in VS Code, Zed, JetBrains) are affected.

The Image Arena Just Reset

  • GPT Image 2.0 Posted the Largest Elo Jump Ever Recorded — On the LMArena image leaderboard, GPT Image 2.0 jumped from 1271 to 1512 — a +242 leap that vaults it past Nano Banana 2 by a full generation. Both Wes Roth and Matthew Berman's torture tests confirmed what the Elo number implies: the model dominates dense text rendering, structured layouts, UI generation, multi-panel character consistency, and even math-in-image reasoning when thinking mode is toggled. Berman's sprite sheets, MrBeast-style thumbnails, and physical-reasoning marble tests all came back cleaner than prior generations. Roth's prediction: an image-to-code front-end model drops within 48 hours to pair with it.
  • SpaceX Reportedly Eyeing $60B/Year Deal for Cursor and Colossus Access — Wes Roth surfaced reporting that SpaceX has an option to acquire Cursor at roughly $60 billion per year, bundled with access to the Colossus supercomputer cluster. If real, this puts the most popular AI coding IDE in the hands of an xAI-adjacent compute empire — another move in the vertical consolidation (model + IDE + compute) that's been quietly reshaping the tooling stack.

The Throughline

A year ago the question was whether AI could reliably find zero-days. This week we got the answer: 271 in Firefox, identified by an early build of Claude Mythos Preview, patched into Firefox 150. Bobby Holley's line — "defenders finally have a chance to win, decisively" — is the optimistic read, and he has the receipts. But the Guardian story landed the same week, about the same model, leaking out of the same vendor supply chain it was supposed to be tested inside. The dual-use problem isn't a thought experiment anymore. It's a calendar entry: on the day Apple and Goldman got official access, a private Discord got unofficial access.

What makes the pricing stories belong in the same issue is that they're the economic shadow cast by those same agents. Anthropic moved Claude Code toward Max plans because agentic sessions are eating compute in ways the original pricing never anticipated. GitHub said the quiet part out loud: long-running, parallelized sessions now regularly consume far more resources than the plan structure was built to support. Six months ago, heavy users were cheap. Now they're not. The pricing flap isn't a marketing misstep — it's a leading indicator that the unit economics of coding agents are repricing in real time, and the companies that ship them are scrambling to keep up.

Put the two threads together and the shape gets uncomfortable. The capability that makes Firefox 150 safer is the same capability that makes AISI warn UK businesses. The economics that make that capability possible are the same economics that are pushing it out of reach of the $20/month tier. A tool that can find 271 Firefox vulnerabilities in partnership with Mozilla can, in the wrong hands, find 271 in your stack. And the wrong hands don't need to train their own model — they need a sloppy vendor.

Simon Willison's frustration with Anthropic's communication on the pricing change is worth holding onto, because it generalizes. When the product is this powerful, a single employee tweet is not enough. The information asymmetry between what Anthropic knows about Mythos's capabilities, what it communicates publicly, and what leaks through a contractor is exactly the kind of gap that breeds the next bad headline.

The Bigger Picture

Bobby Holley's "defenders finally have a chance to win" is the headline defenders want. The quieter reality is that defender advantage requires a containment story, and this week's containment story has a hole in it named "third-party vendor environment." A single contractor compromise unlocked the same offensive capability that Mozilla spent months channeling into patches. The defender-advantage argument and the attacker-advantage reality are not competing theses — they coexist, and the delta between them is set by operational discipline at every lab and every vendor they touch.

Meanwhile the economics are drawing a sharper line. If Claude Code moves to $100/month Max plans and GitHub restricts Opus 4.7 to Pro+, the gap between who can afford powerful coding agents and who can't widens exactly as those agents become the tooling that determines competitive advantage. Willison's point about Codex staying on free and $20 tiers isn't a tactical observation — it's a hint about which platform journalists, students, and hobbyists will learn on, and therefore which platform the next generation of developers will default to. Pricing decisions made this quarter are talent pipeline decisions for the next five years.

The concentration of offensive capability plus the concentration of access equals a trajectory worth naming. A small number of labs hold the most capable models. A shrinking number of users can afford the most capable agents. A single vendor slip-up collapses the containment. This is not where you want to be when the defender-advantage window starts to close.

What to Watch

  • Will Anthropic name the third-party vendor and publish what changed? The leak happened through a contractor environment. The trust-building move is transparency about which vendor, what policy gap, and what new vetting is in place before the next Mythos handoff. If Anthropic stays quiet, expect the story to get worse, not smaller.
  • Does GitHub's token-cap model become the industry default? If per-token caps on weekly and per-session bases prove workable for GitHub's billion-dollar Copilot business, expect every other platform to follow within a quarter. The question is whether the cap tiers price out hobbyists and solo developers — and whether Codex's free tier survives long enough to matter.
  • How quickly does Mythos-level capability escape more broadly? A private Discord today. A cybersecurity-prompt run tomorrow. An open-source equivalent within a year. The discovery-exploitation window Anthropic warned about in March is still closing, and this week's leak is the first data point on how fast.
