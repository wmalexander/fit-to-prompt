WP Rocket is being used to plant PHP files on sites; update to 3.24.2

Yesterday's issue listed this as a patch-soon bug with no known attacks. That has changed. Patchstack says an attacker with no login can make a site download a file from a server they control, save it as PHP and run it. It affects versions before 3.24.2 when either "LazyLoad for CSS background images" or "Host Fonts Locally" is turned on. Both are off by default but common on tuned sites. Patchstack saw the first attempt on November 25 at 15:27 UTC and reports tens of thousands of blocked attempts on November 26 alone, from several separate attackers. Requests go to /wp-admin/admin-ajax.php with the action rocket_beacon. Patchstack puts the plugin at more than 5.5 million sites, which is its own figure. NVD calls the flaw a path traversal and scores it 9.8; Patchstack describes it as remote code execution.

DoUpdate WP Rocket to 3.24.2 or later. If you cannot yet, switch off both options above. The update does not remove files already planted, so look for unfamiliar PHP files such as wp-media-*.php in wp-content, wp-content/uploads and wp-content/wp-rocket-config, and for outbound requests to nip.io or trycloudflare.com names.

Sources: Patchstack · NVD
ExploitedChains to code executionGeoServerJava

GeoServer: CISA says two bugs are exploited; update to 2.27.7, 2.28.6 or 3.0.2

GeoServer is a Java server that publishes map data on the web. On November 27 CISA added two of its bugs to the exploited list. One lets a stranger slip XML into a WFS GetFeatureById request, which can read a text file from the server or make the server fetch a web address of the attacker's choosing. The other lets a request skip the service-level permission checks by putting a prefix in front of the service name, such as x/WFS. CISA says these can be chained with three other GeoServer bugs to get remote code execution with no login. The project's advisories date from November 23. None of these CVE numbers are in NVD yet, so this issue does not print them; the KEV entries and advisories name them. CISA set a due date of November 30 for federal agencies.

DoUpdate GeoServer to 2.27.7, 2.28.6 or 3.0.2. If you cannot today, restrict or turn off WFS for anonymous users, which is the project's stated mitigation for the XML bug. Treat any GeoServer that was reachable from the internet as possibly visited and check its logs.

Sources: GeoServer advisory (XML bug) · GeoServer advisory (permission bypass) · CISA KEV catalog

WebinarIgnition can hand out the wrong user role

NVD lists an incorrect privilege assignment bug in every version through 4.28.1 and scores it 9.8, which means no login is needed. The record says only that it allows privilege escalation, and no attacks are reported.

DoUpdate WebinarIgnition to 4.29.4, the current release, and check your user list for administrator accounts you did not create.

Sources: WordPress.org · NVD

WPMasterToolKit has a code injection bug scored 9.9

NVD lists a code injection bug in every version through 2.26.1. The 9.9 score points to a low-privilege login being enough, but the record gives no further detail and no attacks are reported.

DoUpdate WPMasterToolKit to 2.26.3, the current release, or remove it if you do not use it.

Sources: WordPress.org · NVD
CVSS 7.5 (v3.1)CVE-2026-135626WordPressSimple Membership

Simple Membership: a contributor can make an administrator

In versions through 4.9.0 a user with Contributor access or above can create a membership level that names the administrator role, then have that role applied to a member account. The plugin never checks the role against an allowed list. This is a second Simple Membership bug in two days.

DoUpdate Simple Membership to 4.9.1, and review who holds contributor accounts and which membership levels exist.

Sources: WordPress.org · NVD
CVSS 8.7 (v4.0)CVE-2026-134129PHPComposer

smalot/pdfparser: a small crafted PDF can tie up PHP workers

Before 2.14.0, this PHP library for reading PDFs takes far longer than it should on a file with deeply nested, unbalanced parentheses in a text string. A small upload can stall a worker for seconds to minutes. It matters for any site that parses uploaded PDFs, such as search indexing or document import plugins. NVD has not analyzed the record yet.

DoRun composer update smalot/pdfparser to get 2.14.0 or later, and cap upload size and parse time where users can send PDFs.

Sources: NVD

Supply chainCheckoutBlack Friday

Card skimmers on five shop sites used WebRTC to slip past script rules

InfoHawk found a card-skimming script on the shops of Lascana, Samsonite, American Tourister, Revolve and FWRD in the week before Black Friday. It got onto pages three ways: an altered marketing pixel, a changed cookie-banner setting, and an altered file on a retailer's own CDN. It ran only on phone-sized screens, and the Samsonite version only on the checkout page. The setup requests are ordinary web requests, but the stolen data and the skimmer code travel over a WebRTC data channel, which a connect-src rule does not cover. InfoHawk saw test card details leave Lascana's checkout this way. All five sites removed the code on November 24 or 25. The researchers do not know how many real cards were taken.

DoOn every payment page, set a Content-Security-Policy connect-src that lists only the hosts you use, since that blocks the two web requests the skimmer needs before WebRTC opens. Then check tag managers, cookie-banner settings and CDN files for scripts from S3 buckets named like brand-static, and test checkout on a phone, because desktop checks miss it.

Sources: InfoHawk
Supply chainGitHubCI

PolinRider malware was force-pushed into open pull requests, and one project's release build ran it

StepSecurity reports that an account now suspended by GitHub swapped malware into open pull requests at AsyncAPI, CircuitVerse, Open Food Facts and Jaeger, then replaced it with clean code within 30 to 40 minutes at AsyncAPI. At CircuitVerse the pull request workflows ran it, including the release workflow that built 40 desktop installers, which the maintainers deleted. Open Food Facts' CI ran it too and the project rotated a secret. None of the account's 145 merged pull requests contained the loader.

DoRequire maintainer approval before CI runs on pull requests from forks, keep release workflows off pull request triggers, and rotate any secret a pull request workflow could read.

Sources: StepSecurity
CVSS 9.3 (v4.0)CVE-2026-137964ToolJetGitHub Actions

ToolJet's own release workflow ran shell commands hidden in a pull request title

Before 3.21.96-LTS, ToolJet's GitHub Actions release workflow put the pull request title straight into a shell command. A title with shell characters, merged into a release branch, would run with a token that reaches other repositories. This is a bug in ToolJet's project setup, and the same pattern can sit in any workflow that inserts titles or branch names into a script.

DoIf you run ToolJet, use 3.21.96-LTS or later. In your own workflows, pass titles and branch names in through environment variables, never directly into run blocks.

Sources: NVD
BreachGitHub

SAP confirms an incident after reports that stolen tokens let attackers copy and change code on GitHub

SAP says it found suspicious activity and acted to protect customers, and that it has found no evidence of unauthorized access to customer business data. Der Spiegel, citing an internal memo, reports the attackers stole employee authentication tokens and used them to copy and alter source code. AI-assisted attackSwitzerland

Switzerland says AI agents broke into organizations in four of five reported attacks

The head of Switzerland's national cyber security agency told public broadcaster SRF that AI agents got into systems at Swiss organizations in four of five confirmed cases, the first such cases in the country. Three of the five targeted critical infrastructure operators and two of those succeeded, with no major disruption reported. The victims are not named and no one has been tied to the attacks. The agency says these agents scan for known, unpatched weaknesses, run many attacks at once, and switch methods when defenses respond. It also says the number of AI attack tools reachable online has nearly doubled since October, a count of tools and not of victims.

DoTreat the time between a patch release and attempted exploitation as hours, not weeks. Start with the internet-facing items in this issue, such as WP Rocket and GeoServer.

Sources: The Hacker News
