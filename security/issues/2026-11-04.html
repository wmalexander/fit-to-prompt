ExploitedCVSS 8.1CVE-2026-119977WordPress core

Attackers are now exploiting the WordPress core upgrade bug

During a full core update, WordPress 4.7 through 7.1.3 unpacks the new files, including the installer, into a predictable folder under wp-content/upgrade that the web can often reach. An attacker who hits that folder in the few seconds it exists can run code without an account. Attackers are polling for it constantly: Wordfence recorded more than 18,500 probes in the first 21 hours, and CISA added the bug to its exploited list on November 3.

WordPress 7.1.4 shipped October 28 with fixes for 22 vulnerabilities, and every older branch back to 4.7 got its own security release. Automatic background updates should have applied it, but Wordfence advises checking rather than assuming. Wordfence's firewall rule reaches free users only on November 27.

DoConfirm each site reports 7.1.4, or the matching release for its branch (for example 7.0.8, 6.9.11, 6.8.12), under Dashboard > Updates.

Sources: WordPress.org · Wordfence · NVD · The Hacker News
ExploitedCVSS 9.2CVE-2026-111497Server library

HTTP2Shell is a server problem, not a WordPress update

The bug nicknamed HTTP2Shell is a buffer overflow in Google's Brotli decoder, versions 1.0.3 through 1.2.0. A crafted compressed response can corrupt memory and may lead to remote code execution. Wordfence reproduced code execution through WordPress in a lab, using the XML-RPC pingback feature to make the site fetch a malicious response, but the public exploit only worked on the exact server setup it was built for. CISA lists the bug as exploited; Wordfence says the public reports it reviewed through November 2 do not document a confirmed compromise through WordPress.

DoHave your host or server team update Brotli to 1.0.10, 1.1.1 or 1.2.1 and restart the services that load it. Turning off XML-RPC pingbacks you do not use closes the route shown in the public exploit.

Sources: Wordfence · NVD
Supply chaincPanel serversNo CVE

cPGuard's own update channel delivered a backdoor

On November 2 an attacker used stolen credentials to get into the update system for cPGuard, a security tool for cPanel servers, and pushed a malicious script in versions 5.88.12 through 5.88.19. The script installed a backdoor and copied /etc/shadow, root's MySQL or MariaDB config, root's shell history and SSH files. Maker OPSSHIELD says it caught the attack within 12 hours, but it has not said how many servers took the update.

DoUpdate to 5.88.25 or later, search the cPGuard update log for 5.88.12 through 5.88.19, and if you find one (or cannot tell), rotate root, database and SSH credentials and treat the server as compromised.

Sources: The Hacker News · SecurityWeek

CVSS 10.0CVE-2026-81648PluginNo fix

Attackers probe an unpatched crypto payment plugin

The CryptoPayment Gateway plugin, versions 1.2.1 through 1.2.2, skips an authorization check on an AJAX endpoint, so anyone can delete files, rewrite the gateway settings and read stored wallet credentials in plain text. Defused Cyber reports exploitation attempts. There is no fix, and WordPress.org closed the plugin in August after about 1,845 total downloads.

DoRemove the plugin, rotate any wallet keys it stored, and check for unexpected file or setting changes.

Sources: The Hacker News · NVD
CVSS 9.8CVE-2026-120534Plugin

Advanced Custom Fields: Extended PRO lets visitors call WordPress functions

Versions up to 0.9.2.6 can let an unauthenticated visitor call arbitrary WordPress functions with chosen arguments. It only works if an admin enabled the non-default shortcode preview setting on a form, or if the server lacks OpenSSL functions. Update to the newest release.

PHPComposer 2.11

Composer can now wait before installing brand-new package versions

Composer 2.11 adds a config.policy.cooldown setting that holds newly published versions back for a set number of hours, days or weeks during composer update and composer require. The idea is that a hijacked release is often caught and pulled before the waiting period ends. It is off by default, and Socket says urgent security updates can still get through.

AI × security

AI-found bugs, AI-assisted attacks, prompt injection, coding agents

API keysCVE-2026-40217LiteLLM

Stolen LLM keys are costing some companies up to $1 million

Google's threat intelligence group and Mandiant describe "LLMjacking" crews who find exposed AI endpoints or steal API keys, cloud credentials and GitHub tokens, then resell the access through cheap "unlimited" proxy services. One actor made more than 500,000 calls in under eight hours. Some victims saw more than $100,000 in charges in a single day. Attackers have also exploited a LiteLLM bug that runs code through its guardrail test endpoint.

DoKeep LLM keys in a secrets manager rather than .env files in repos, scope and rotate them, set provider spending alerts, and do not expose LiteLLM admin endpoints to the internet.

Sources: BleepingComputer · NVD
Developer machines

The Binance theft started on engineers' laptops

Binance's first report on the $6.34 billion theft says it began in June, when an engineer searching for an AI coding tool downloaded a tampered Homebrew install. A second engineer later ran a fake job-interview coding assignment that hid malware. The attackers then used an internal AI tool to take over more machines; the report does not explain how. The FBI attributes the theft to North Korea's TraderTraitor group, which North Korea denies.

AI attack tools

WorkOS says an AI attack framework breached its sales app

The identity platform says an attacker reached an internal sales tool and took CRM contacts and summaries of customer conversations, but not app data or production systems. Its founder says the attacker used ARTEX AI, an AI penetration testing suite seen in several attacks this year. Its user agents included artex-enrich/1.0 and norma/0.4, which are worth searching your logs for.

RansomwareUnconfirmed AI

Ransomware at a UK school looked like an AI agent loop

Bitdefender saw commands that changed slightly on each retry, issued every 40 to 100 seconds, in an attack that encrypted about 37 of nearly 50 machines. Researchers say this looked like an AI agent loop, but they could not see the attacker's machine to confirm it.

Today's checklist

  • Confirm every WordPress site runs 7.1.4 or its branch's patched release.
  • Ask your host, or check your servers, for Brotli 1.0.10, 1.1.1 or 1.2.1, then restart the services that use it.
  • If you run cPGuard, update to 5.88.25 or later, check the update log for 5.88.12 through 5.88.19, and rotate credentials if found.
  • Remove CryptoPayment Gateway and update ACF: Extended PRO.
  • Move LLM API keys out of repos, set spending alerts, and rotate any key that has lived in a .env file.
