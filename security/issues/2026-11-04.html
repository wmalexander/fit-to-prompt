ExploitedCVSS 8.1CVE-2026-119977WordPress core

Attackers are now exploiting the WordPress core upgrade bug

During a full core update, WordPress 4.7 through 7.1.3 unpacks the new files, including the installer, into a predictable folder under wp-content/upgrade that the web can often reach. An attacker who hits that folder in the few seconds it exists can run code without an account. Attackers are polling for it constantly: Wordfence recorded more than 18,500 probes in the first 21 hours, and CISA added the bug to its exploited list on November 3.

WordPress 7.1.4 shipped October 28 with fixes for 22 vulnerabilities, and every older branch back to 4.7 got its own security release. Automatic background updates should have applied it, but Wordfence advises checking rather than assuming. Wordfence's firewall rule reaches free users only on November 27.

DoConfirm each site reports 7.1.4, or the matching release for its branch (for example 7.0.8, 6.9.11, 6.8.12), under Dashboard > Updates.

Sources: WordPress.org · Wordfence · NVD · The Hacker News
ExploitedCVSS 9.2CVE-2026-111497Server library

HTTP2Shell is a server problem, not a WordPress update

The bug nicknamed HTTP2Shell is a buffer overflow in Google's Brotli decoder, versions 1.0.3 through 1.2.0, and it can lead to remote code execution. Wordfence reproduced code execution through WordPress's XML-RPC pingback feature in a lab, but the public exploit only worked on the exact setup it was built for. CISA lists it as exploited; Wordfence found no confirmed compromise through WordPress as of November 2.

DoHave your host update Brotli to 1.0.10, 1.1.1 or 1.2.1 and restart services. Turn off XML-RPC pingbacks you do not use.

Sources: Wordfence · NVD
Supply chaincPanel serversNo CVE

cPGuard's own update channel delivered a backdoor

On November 2 an attacker used stolen credentials to push a malicious script through cPGuard's update system in versions 5.88.12 through 5.88.19. It installed a backdoor and copied /etc/shadow, root's MySQL config, shell history and SSH files. OPSSHIELD caught it within 12 hours but has not said how many servers took the update.

DoUpdate to 5.88.25 or later, search the update log for 5.88.12 through 5.88.19, and if found, rotate root, database and SSH credentials.

Sources: The Hacker News · SecurityWeek

CVSS 10.0CVE-2026-81648PluginNo fix

Attackers probe an unpatched crypto payment plugin

CryptoPayment Gateway 1.2.1 through 1.2.2 skips an authorization check on an AJAX endpoint, so anyone can delete files, rewrite the gateway settings and read stored wallet credentials. Defused Cyber reports exploitation attempts. There is no fix, and WordPress.org closed the plugin in August after about 1,845 downloads.

DoRemove the plugin and rotate any wallet keys it stored.

Sources: The Hacker News · NVD
CVSS 9.8CVE-2026-120534Plugin

ACF: Extended PRO lets visitors call WordPress functions

Versions up to 0.9.2.6 let an unauthenticated visitor call arbitrary WordPress functions, but only if an admin enabled the non-default shortcode preview setting or the server lacks OpenSSL functions. Update to the newest release.

PHPComposer 2.11

Composer can now wait before installing brand-new package versions

Composer 2.11 adds a config.policy.cooldown setting that holds newly published versions back for hours, days or weeks, so a hijacked release is more likely to be caught and pulled before it reaches you. It is off by default; urgent security updates can still get through.

Critical RCEGHSA-2464-fhr4-w9xwGHSA-673q-mjm6-r5xrNext.jsNo CVE yet

Next.js: two critical October bugs, seven more fixes this week

On October 22, Next.js disclosed two unauthenticated remote code execution bugs that do not have CVE numbers yet. One is in the Image Optimization API when SVG files are used, through the sharp image library on glibc-based Linux, and it affects every release from 10.0.0 up to 15.5.27 and 16.0.0 through 16.4.0. The other affects App Router apps whose use cache functions return multiple typed arrays, and has no workaround. On November 3, a second release fixed seven more bugs, one rated High, mostly cached content leaking between users or tenants.

DoUpgrade to Next.js 16.4.5 or 15.5.29, which include every fix above, and make sure sharp is 0.35.5 or newer.

Sources: Next.js · GitHub advisory · GitHub advisory
Severity: HighNode.js 26 / 24 / 22Nov 11

Node.js security releases land November 11

The Node.js project will ship new 26.x, 24.x and 22.x releases on or shortly after Wednesday, November 11. The most serious fix in each line is rated High; details stay private until release day. End-of-life versions are always affected and will not get a patch.

DoBook an update window for November 11 or 12, and move anything still on an end-of-life Node line to 22.x or newer.

Sources: Node.js
CVSS 9.13 critical CVEsApache Tomcat

Tomcat's October releases fix three critical bugs

The worst lets attackers log in without the right password when the JNDI realm uses a non-GSSAPI SASL mechanism (CVE-2026-101296). Another can mix up requests and responses between users on HTTP/2 with asynchronous servlets (CVE-2026-101356). A third can leak part of one response into the next request on 11.x (CVE-2026-103119). Unsupported 8.5 and 7.0 are affected by the login bug too.

DoUpgrade to Tomcat 11.0.27, 10.1.61 or 9.0.123.

Sources: NVD · NVD · NVD
ExploitedCVE-2016-3081Apache Struts

A 2016 Struts bug is under attack again

CISA added this Struts 2.3 command injection bug to its exploited list on October 8 after the China-linked group Flax Typhoon used it. It only works when Dynamic Method Invocation is on. Struts 2.3 is long out of support: move to a current Struts release, and turn Dynamic Method Invocation off in the meantime.

ModerateApache httpd 2.4.69

Apache httpd 2.4.69 fixes 20 bugs, none critical

The October 1 release fixes 20 CVEs, five rated moderate, including a use-after-free in mod_http2 and a lock bug in mod_dav. Nothing is reported exploited, but if you run httpd yourself, roll it into your next maintenance window.

AI × security

AI-found bugs, AI-assisted attacks, prompt injection, coding agents

API keysCVE-2026-40217LiteLLM

Stolen LLM keys are costing some companies up to $1 million

Google's threat intelligence group and Mandiant describe "LLMjacking" crews who find exposed AI endpoints or steal API keys, cloud credentials and GitHub tokens, then resell the access through cheap "unlimited" proxy services. One actor made more than 500,000 calls in under eight hours, and some victims saw more than $100,000 in charges in a day. Attackers have also exploited a LiteLLM bug that runs code through its guardrail test endpoint.

DoKeep LLM keys in a secrets manager rather than .env files in repos, scope and rotate them, set spending alerts, and never expose LiteLLM admin endpoints.

Sources: BleepingComputer · NVD
Developer machines

The Binance theft started on engineers' laptops

Binance says the $6.34 billion theft began when an engineer searching for an AI coding tool downloaded a tampered Homebrew install, and later a fake job-interview coding assignment hid malware. The attackers then used an internal AI tool to take over more machines; the report does not say how.

AI attack tools

WorkOS says an AI attack framework breached its sales app

The identity platform says an attacker took CRM contacts and call summaries, not app data. The founder says the attacker used ARTEX AI; its user agents included artex-enrich/1.0 and norma/0.4, worth searching your logs for.

RansomwareUnconfirmed AI

Ransomware at a UK school looked like an AI agent loop

Bitdefender saw commands that changed slightly on each retry every 40 to 100 seconds. It looked like an AI agent loop, but the researchers could not confirm it.
