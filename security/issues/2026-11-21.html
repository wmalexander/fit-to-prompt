ExploitedCVSS 9.8CVE-2026-129448Apache

Apache Roller 4.0.0 through 6.1.4 can let a stranger run code, and CISA says it is being used in attacks

Apache Roller is a Java blog server. Its XML-RPC address accepts special data types and unpacks them before it checks who is asking, so anyone who can reach that address can make the server run their code. The Roller maintainers said the bug is being exploited, and CISA added it to its Known Exploited Vulnerabilities list on November 20. Federal agencies have until November 23 to fix it. Nobody has said who is behind the attacks or how they are being carried out.

Turning XML-RPC off in the admin screen does not help on old versions, because they unpack the request before they look at that setting.

DoUpgrade Roller to 6.1.6 or later. If you cannot upgrade today, set enabledForExtensions to false in WEB-INF/web.xml or remove the /roller-services/xmlrpc servlet mapping, restart Roller, and look through the logs for XML-RPC requests from strangers.

Sources: The Hacker News on the CISA additions · NVD
CVSS 9.8CVE-2026-120539WordPress

Restrictions for BuddyPress 1.5.4 and earlier runs code from a web address

The plugin pastes part of the page address into PHP code and runs it. One request from a stranger is enough, with no login. It only affects sites that also run BuddyPress and Paid Memberships Pro, and it works with the plugin's default settings. We did not find a public report of attacks, and we could not confirm the plugin's install count.

DoUpdate Restrictions for BuddyPress to 1.5.5 or remove it.

Sources: Plugin release 1.5.5 · NVD
CVSS 9.2 (v4.0)CVE-2026-123007nginx

A public exploit exists for the nginx HTTP/2 bug, but it needs unusual conditions

This is the nginx HTTP/2 bug from earlier this week. StepSecurity says one team published a working exploit. It needs a direct connection to nginx with no HTTP/2 proxy in front, about 119 GiB of traffic within nginx's one-hour connection limit, an otherwise idle server, and an x86-64 CPU with AVX-512. A smaller public tool only crashes the worker. StepSecurity reports no attacks as of November 20, and the bug is not on the CISA list. That is why it is a patch-this-week item rather than a drop-everything one.

DoUpdate nginx to 1.31.9 (mainline) or 1.30.7 (stable), or install your distribution's backport, on every server with HTTP/2 turned on.

Sources: StepSecurity · NVD

WordPress & PHP watch

Core, plugins, themes, PHP and the frameworks on top of it

CVSS 9.2 (v4.0)CVE-2026-126714CVE-2026-129289PHPNo attacks reported

What phpAfterShell and the PHP-FPM bug need before they work, and what Cloudflare blocks

The PHP releases from November 19 fix phpAfterShell, a flaw in PHP's default file-based session storage. If a session write is cut short, the file can mix new and old data, and PHP can then rebuild objects an attacker chose. It needs an attacker who can influence session data (for example through PHP's upload-progress feature), a badly timed interruption, and a suitable code path in the application, so it is hard to pull off. The same releases fix a PHP-FPM bug that lets a stranger forge a second request, but only where the front end reuses connections to PHP-FPM (nginx with fastcgi_keep_conn on, Apache mod_proxy_fcgi with enablereuse=on, or HAProxy), which is not the default.

Cloudflare says its firewall blocks known phpAfterShell patterns on every plan, including Free, and that it saw no reports of attacks as of November 19. Its new rules for the PHP-FPM bug and two SOAP bugs start in log-only mode on paid plans. Cloudflare is clear that a firewall rule is an extra layer and not a replacement for the patch.

DoUpdate PHP to 8.2.36, 8.3.37, 8.4.28 or 8.5.13 and restart every PHP-FPM pool and worker. On Linux, check your distribution's advisory, because fixes are often backported without a version change.

Sources: Cloudflare · Wordfence · NVD (126714) · NVD (129289)
CVSS 9.8CVE-2026-80188WordPress

BuddyBoss Addons 1.2.1 and earlier lets a stranger sign in as any user who has an email address on file

The social login endpoint trusts Apple and Facebook sign-in claims without checking them, so an attacker who knows a user's email address, including an administrator's, can link their own login to that account. It needs BuddyBoss Platform active with the Social Login module and a provider turned on.

DoUpdate BuddyBoss Addons to 1.2.2.

Sources: BuddyBoss release notes · NVD
CVSS 9.8CVE-2026-129073WordPress

miniOrange OTP Verification 5.6.1 and earlier has a way around its login check

NVD lists an authentication bypass through an alternate path in the plugin, which WordPress.org shows with about 5,000 active installs. The record gives no detail beyond that, and no public attacks were found.

DoUpdate to 5.6.2 or later, the version WordPress.org lists now, and read its changelog to confirm the fix.

Sources: WordPress.org plugin page · NVD

One unpacks untrusted data (9.8) and one allows SQL injection (9.3). WordPress.org lists about 2,000 installs and 4.18.3 as current. Update to 4.18.3 or later, and check its changelog for the fix.

Node.js, React & Apache watch

The runtime, the front-end framework and the servers under a lot of the web

CVSS 9.0CVE-2026-133212Node.js

@fastify/reply-from before 12.9.1 can let an attacker sneak a second request through your proxy

When this Fastify proxy plugin forwards a request with a body it does not send (a GET with a body, or an empty JSON body), it still passes along the Content-Length header. The server behind it then reads the next request as the missing body, which lets an attacker slip a request past the proxy. We did not find reports of attacks.

DoUpgrade @fastify/reply-from to 12.9.1 or later and rerun your lockfile install.

Sources: NVD

Web stack & supply chain

npm, Composer, PyPI, browsers, CI, hosting

CVSS 9.3 (v4.0)CVE-2026-133949PyPI

pip before 26.2.2 ships a certificate bundle that still trusts compromised eMudhra certificates

The certificate list bundled inside pip still includes certificates from eMudhra that were found to be compromised, so pip could trust a connection it should refuse. Python itself added a block list for these certificates (CVE-2026-115557), and pip is not affected when it runs on a Python version that rejects them. NVD lists this record as not yet analyzed.

DoUpgrade pip to 26.2.2 or later, or use a Python version that rejects the compromised certificates, and use hash pinning in CI.

Sources: NVD (pip) · NVD (Python)

AI × security

AI-found bugs, AI-assisted attacks, prompt injection, coding agents

ExploitedCVSS 9.8CVE-2026-133968AI-found bug

An AI agent tool found a new MONAI Label bug and took over a server in minutes

Amazon says suspected Chinese attackers pointed an AI penetration-testing tool called Cairn at East Asian universities and told it to "obtain shell access." The agents found a file-path bug in MONAI Label, a medical imaging server, and went from mapping its API to exploiting it in 11 minutes. They failed against a Redis server and a GPU server, so the tool is not magic. Amazon attributes the activity with moderate confidence and says the attackers left their Cairn server open to the internet. The CVE covers MONAI Label 0.8.5 and earlier; Amazon says the maintainers shipped a fix on November 18.

DoIf you run MONAI Label, install the release the maintainers published after November 18 and keep it off the public internet.

Sources: The Record on Amazon's report · NVD
Incident

Bell Canada says an "agentic" attacker took enterprise customer data

Bell says an attacker it calls agentic got into some systems on November 17, including a pre-production system used to order circuits, and copied business contact details and some IP addresses. Bell says no credentials were taken. The word suggests AI tools were used, but Bell has not said so directly.
