ExploitedCVSS 9.2 v4.0CVE-2026-109618CVSS 9.2 v4.0CVE-2026-109619PHP

Two PHP bugs that let a stranger run code on the server are now on CISA's exploited list

Both bugs are in how PHP handles a request's memory, so they do not depend on a flaw in your app. CVE-2026-109618 comes from an out-of-memory error leaving data half set up, and CVE-2026-109619 comes from leftover state pointing at freed memory. NVD lists PHP 7.3.0 up to 8.2.35, 8.3 before 8.3.36, 8.4 before 8.4.27 and 8.5 before 8.5.12 as affected. Arctic Wolf says Apache with mod_php, PHP-FPM, php-cgi, FrankenPHP and LiteSpeed are all in scope, and that mod_php has the clearest demonstrated attack, in one request with no login. CISA added both on October 26. Public exploit code exists, but Arctic Wolf says most activity it sees is scanning, with few reliable attacks at scale. Check Point reports that attackers used PHP2Shell activity against the Mobile Access portal of unpatched Check Point gateways starting October 30, then used a separate root-access bug (CVE-2026-123039, 7.8 v3.1, not in KEV) to install a backdoor and, in some cases, wipe a VMware ESXi host. Arctic Wolf says the PHP bugs were found with AI-assisted research.

DoRun php -v on every server and container, and upgrade to 8.5.12, 8.4.27, 8.3.36 or 8.2.35. PHP 7.x and 8.1 get no upstream fix, so use your OS vendor's backport or move to a supported branch. If you run Check Point gateways with Mobile Access, apply Check Point's fix for those bugs and the Gaia OS bug.

Sources: PHP 8.5.12 release · PHP security advisory · Arctic Wolf · The Hacker News on Check Point · NVD 109618 · NVD 109619 · NVD 123039
ExploitedCVSS 9.3 v4.0CVE-2026-116606CVSS 8.6 v4.0CVE-2026-111560Barracuda

Barracuda gateways can be taken over by chaining two bugs, and attackers are doing it

CVE-2026-116606 is a login bypass in Barracuda Email Security Gateway versions before 9.4.0.030 that lets someone restore a crafted backup and change the appliance's settings. CVE-2026-111560 lets an administrator run commands as root on the Email Security Gateway, Load Balancer ADC, Web Application Firewall, Web Security Gateway, Message Archiver and WAF Control Center. Together they give root access. Barracuda says a small number of organizations were attacked, and CISA added both on November 10 with a November 13 deadline. Previdian counted 17 attempts against the first bug between November 9 and 11.

DoUpdate every Barracuda product to the fixed release in Barracuda's November 2 advisory, and make sure the admin interface is not reachable from the internet.

Sources: SecurityWeek · NVD 116606 · NVD 111560
CVSS 9.5 v4.0CVE-2026-118383MongoDB

A critical MongoDB bug lets an unauthenticated client crash a server after a failover

Two requests with no login can leave a replica set member holding a booby-trapped waiting task. If that member later wins an election while still behind, it crashes before taking writes. Replica set, shard and config server members are affected; a standalone mongod is not. MongoDB rates it 9.5 and says it knows of no attacks. It mentions possible code execution, but Datadog's lab only produced a crash. Atlas clusters get the fix during maintenance.

DoUpgrade every self-managed replica set member to the fixed release for your branch (8.0.37 is the fix on 8.0), then check the version each member reports. Until then, limit network access to the database.

Sources: The Hacker News · NVD

WordPress & PHP watch

Core, plugins, themes, PHP and the frameworks on top of it

CVSS 9.8 v3.1CVE-2026-110959WordPress

Descope plugin before 1.2.0 accepts any login token and signs the visitor in as an admin

Per NVD, the Descope plugin before 1.2.0 does not check the token it receives, so an unauthenticated attacker can get a session for any account, including an administrator, by supplying that account's email address. Update Descope to 1.2.0 or later.

CVSS 9.8 v3.1CVE-2026-124814WordPress

Ultimate Addons for Elementor Forms before 1.0.8 lets strangers upload PHP files

Per NVD, the file upload field does not check file extensions, so an unauthenticated visitor can upload a PHP script and run code. Update to 1.0.8 or later, and look for unexpected .php files in your uploads folder.

CVSS 10.0 v3.1CVE-2026-124815WordPress

Clockinator Lite before 1.1.0 lets strangers delete and read data from any database table

Per NVD, several delete actions have no access check and take a table name from the visitor, so an unauthenticated attacker can run SQL injection. Update to 1.1.0 or later, or deactivate the plugin.

CVSS 8.6 v3.1CVE-2026-124647WordPress

TI WooCommerce Wishlist before 2.0.7 has an SQL injection that needs no login

Per NVD, user input reaches a database query unescaped in a front-end endpoint. Update to 2.0.7 or later on any store that uses the wishlist.

CVSS 8.1 v3.1CVE-2026-111579WordPress

Forminator Forms before 1.58.4 can hand out an admin role without payment

Per NVD, when a payment-gated registration form's payment gateway is unavailable, Forminator does not enforce payment on the server, so a visitor can register without paying and get the form's configured role, up to administrator. Update to 1.58.4 or later.

Weekly count

Wordfence counted 497 new plugin vulnerabilities in the week of November 2 to 8

Wordfence's own report says 497 vulnerabilities in 312 plugins and one theme were added to its database that week, reported by 218 researchers. The figures are a week old and I read only the summary, but they show why keeping plugins updated on a schedule matters.

The runtime, the front-end framework and the servers under a lot of the web

Apache httpdCVE-2026-119618

Apache's HTTP/2 bug from yesterday is still open, and it was found by AI scanners

Apache credits Anthropic's OSS Scanner, which reported it on October 26, and two Google Cloud researchers who found it independently on November 3. A public proof of concept on GitHub reproduces crashes but does not show code execution. Defiant warns that WordPress updates cannot fix it because the bug is in the web server. Upgrade to 2.4.71 or set Protocols http/1.1. NVD still shows no score.

Node.jsReact

Nothing new for Node.js, React or Next.js today, and two fixes from this week are still open

None of today's feeds posted a new Node.js, React or Next.js release. Still open from this week: Node.js 22.23.5, 24.22.3 and 26.13.1, and React Server Components packages 19.0.9, 19.1.10, 19.2.9 and 19.3.1 (CVE-2026-126187). Confirm your servers and lockfiles use them.

Active campaignGitHub ActionsPackagist

The GitHub secret-stealing campaign grew: 4,837 hijacked accounts probed 61,764 repositories

Aikido says the wfx-loot attacker has stolen secrets from at least 1,835 targets, and 92% of its pull requests are still open. Automated publishing also pushed the payload into the Packagist package digitalelvis/neuronai-studio 3.14.3 and two versions of a Go module, v1.0.278 and v1.0.280 of onuragtas/docker-env. Close any open pull request titled docs: dependency audit notes, and rotate secrets if a workflow ran one.

Citrix fixes 12 NetScaler flaws, including a login bypass on NetScaler Console

CVE-2026-120868 is a memory bug in packet handling that can crash any NetScaler ADC or Gateway. CVE-2026-120869 lets an unauthenticated attacker skip authentication on NetScaler Console. Citrix lists 14.1-73.57 and 13.1-64.39 as the fixed ADC and Gateway builds. I found no report of attacks.

Pillow up to 12.3.0 can overflow memory when saving some TIFF images

Python sites that save TIFFs through Pillow with custom size tags can hit a heap buffer overflow. GitHub's advisory lists 13.0.0 as the patched version. Upgrade Pillow if your app resizes or re-saves user uploads as TIFF.

AI × security

AI-found bugs, AI-assisted attacks, prompt injection, coding agents

Active campaignAI agent

Attackers used an open-source AI pentest tool to break into 10 of 19 targeted organizations

Unit 42 says Chinese-speaking attackers ran the open-source Cairn framework, paired with the Zhipu GLM and DeepSeek models, in 25 operations against at least 19 organizations in August and September. Given only a target and a goal, it planned and ran its own steps. It got in at 10 of them, including dozens of valid credentials, more than a million personal records at one organization, and new administrator accounts on a production system. Unit 42 tracks the group as CL-STA-1238 and has moderate confidence it is China-linked intelligence collection. The article lists indicators such as 154.44.31[.]4 and 82.29.129[.]54.

DoAssume your logins and admin panels are probed by tools that do not tire. Turn on MFA for admin accounts, rotate any credential that has appeared in a leak, and compare your firewall logs against Unit 42's indicator list.

Sources: Unit 42 · SecurityWeek on a related campaign
