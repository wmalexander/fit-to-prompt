Cacti can be taken over without a login in four requests

Cacti is a PHP tool many teams use to watch their network. A researcher published a working exploit that goes from an anonymous visit to running commands on the server in four web requests. It works on Cacti Core 1.2.31, the latest version, when the guest account is turned on. Guest has been off by default since version 0.8.7. The bug lets a guest save text that is not a number into a graph setting, and that text later runs as part of a database query. From there an attacker can change a poller entry so the server runs a command. Cacti often stores logins for routers, switches and servers, so a break-in can spread well beyond the monitoring box. No CVE number has been assigned and The Hacker News does not report attacks in the wild yet.

DoTurn off the guest account today, limit who can reach the Cacti web interface, and look through poller entries for commands you did not add. Install the fix as soon as the Cacti project ships one.

Sources: The Hacker News · watchTowr FAQ · Cacti releases

Ultimate Member through 2.14.1 has a critical object injection bug

Ultimate Member runs membership, login and profile pages on many WordPress sites. NVD lists an unsafe deserialization bug (PHP object injection) in every version through 2.14.1 and scores it 9.8, which means no login is needed. NVD gives no exploit detail yet, and this issue found no report of attacks.

DoUpdate to Ultimate Member 2.14.3, the current release on WordPress.org, and check the plugin changelog for the fix note.

Sources: WordPress.org · NVD
CVSS 9.8 (v3.1)CVE-2026-131767WordPressFunnelKit Automations

FunnelKit Automations through 3.9.0.1 has the same kind of bug

FunnelKit Automations handles email marketing and customer records for WordPress and WooCommerce stores. NVD lists a PHP object injection bug in every version through 3.9.0.1 and scores it 9.8. Details are thin and no attacks are reported.

DoUpdate to FunnelKit Automations 3.9.0.2, the current release, and confirm the version on each store.

Sources: WordPress.org · NVD

WordPress & PHP watch

Core, plugins, themes, PHP and the frameworks on top of it

CVSS 8.1 (v3.1)CVE-2026-119071WordPressW3 Total Cache

W3 Total Cache lets post editors delete other media files

In versions through 2.11.0, a setting that any user who can edit a post can write is later used to pick which attachments get deleted, with no check that they belong to that user. A contributor account could remove media it does not own.

DoUpdate W3 Total Cache to 2.11.1 and review who has editor or contributor accounts.

Sources: WordPress.org · NVD
CVSS 9.1 (v3.1)CVE-2026-133951WordPressSimple Membership

Simple Membership made its signing secret too easy to guess

Through version 4.8.9, the plugin creates its site-wide secret with a weak random function. The guess space is small enough that an attacker can narrow it using the public date of the registration page, then use the registration form to check the guess and raise their own access level.

DoUpdate Simple Membership to 4.9.1, the current release. Check the changelog on whether the secret is regenerated, and review members with elevated levels.

Sources: WordPress.org · NVD
CVSS 8.2 (v4.0)CVE-2026-137559PHPComposer

web-token jwt-framework: tiny tokens can keep PHP workers busy for minutes

On PHP without the GMP extension, the library does slow math on oversized key values before checking their length. An unauthenticated caller who knows only the curve can send small encrypted tokens that tie up a worker for seconds to minutes each. Fixed in 3.4.13, 4.0.9, 4.1.11 and 4.2.6. Run composer update web-token/jwt-framework web-token/jwt-library, or install the GMP extension.

Sources: NVD

Node.js, React & Apache watch

The runtime, the front-end framework and the servers under a lot of the web

CVSS 9.1 (v3.1)CVE-2026-135279FastifyNode.js

@fastify/express can skip Express middleware on some routes

The plugin lets Express middleware run inside a Fastify app. Before 4.0.14, a request with an empty route parameter reaches the Fastify handler while middleware mounted inside an Express router is skipped, and a loose regular-expression mount is skipped the same way. An earlier fix covered only some mounts. NVD says this can bypass authentication.

DoUpdate @fastify/express to 4.0.14, and do not rely on Express middleware alone to protect a route.

Sources: NVD
CVSS 9.1 (v4.0)CVE-2026-137465Parse Server

Parse Server: Google Play Games login can be used to take over accounts

The adapter does not check that the player ID belongs to the access token, so an attacker can sign in with their own credential while naming someone else's ID. It affects 3.10.0 before 8.6.123 and 9.0.0 before 9.11.1-alpha.4, and only apps using that adapter. Update, or turn the adapter off.

Web stack & supply chain

npm, Composer, PyPI, browsers, CI, hosting

Supply chainGitHubPythonNorth Korea-linked

PolinRider hides a loader in a small utils package or conftest.py

SafeDep found a Python loader in 375 public GitHub repositories from 260 accounts. It sits in a small utils package or in conftest.py, so it runs when Python imports the file or when tests start. The loader reads the newest transaction an Ethereum wallet sent to itself, decodes it as JavaScript and runs it with Node.js, which then looks up a second wallet to find its command server. The Hacker News headline puts the wider PolinRider campaign at over 7,600 repositories, and reports it may date back to February 2025. SafeDep found no sign of it on PyPI or npm. Fake job interviews are one delivery route, with take-home projects, a fake camera check that asks for a driver, and copy-and-paste terminal commands.

DoSearch your repos and forks for odd code in conftest.py and small utils packages, run take-home or unknown projects only in a throwaway virtual machine, and if you ran one on a work laptop, rotate your GitHub tokens and check for pushes you did not make.

Sources: The Hacker News (citing SafeDep, StepSecurity and Unit 42)

Microsoft's Edge Extensions Security Team documented over 250 extensions on the Edge, Chrome and Firefox stores. E-commerceSkimmers

Guardio: about 1 in 195 online shops scanned was hijacked in October

Guardio Labs (a vendor, measuring its own scan) says about 12,200 of 2.38 million stores were hijacked. Tactics include sending shoppers to scam pages, fake "I'm not a robot" checks that tell them to paste a command (about 900 shops), and card skimmers. Store owners should review checkout scripts and update their plugins.

AI × security

AI-found bugs, AI-assisted attacks, prompt injection, coding agents

ExploitedSuspected AI useMitel MiCollab

Mitel MiCollab: attackers used the bugs before the patch, and may have used AI

Accenture's Apex Labs says five MiCollab conferencing bugs were used as zero-days before Mitel's Nov 16 patches. One attacker ran commands 12 minutes after the first request, had root in half an hour, and reached backup and database servers about 20 hours in. The attacker's servers also talked to two commercial AI services, which Accenture calls consistent with sorting stolen data, helping with the web shell and preparing extortion, but it cannot say how they were used. CISA added the five bugs to its exploited list on Nov 25. This is not a web stack product, but the speed is the lesson.

DoPatch MiCollab using Mitel's Nov 16 advisory. If a server was exposed before patching, treat it as possibly compromised and check Accenture's indicators of compromise.

Sources: SecurityWeek · CISA KEV
CVSS 8.1 (v3.1)CVE-2026-131688WordPressMCP

A WordPress MCP plugin turns any valid agent token into an admin

The Secure MCP Server for Claude, ChatGPT, Gemini, Cursor and other AI Agents plugin, through 1.5.8, does not check who is allowed to do what. Per NVD, an attacker holding any valid MCP bearer token, even a limited test token, can act with the token owner's Administrator role by sending it to endpoints such as admin-ajax.php. Getting a token is the hard part, but tokens leak into config files and logs.

DoUpdate the plugin once a release newer than 1.5.8 is out (this issue could not confirm a fixed version), revoke unused MCP tokens, and give each token only the scope it needs.

Sources: NVD
