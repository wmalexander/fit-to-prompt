ExploitedCVSS 8.1CVE-2026-119977WordPress

Updating WordPress to fix the core upgrade bug can still leave a site open for a moment

The researcher who found the bug says the update that installs the fix still unpacks its files using the site's old code. On sites running 5.9 or later, that old code names the temporary folder after the downloaded file, so an attacker can guess the name one last time and run code on the server before the folder is deleted. The risk depends on whether the updater already on the site has been fixed, and a full update package always carries the installer files. Wordfence saw attack attempts begin nine minutes after it deployed a firewall rule, and two busy sources kept checking small groups of sites for about 14.5 hours. In its lab tests the window lasted only seconds. WordPress's own advisory rates the bug low, and code described as an exploit has appeared on GitHub, though whether it works has not been established. Versions 4.6 and earlier get no fix.

DoBefore you update, block web access to wp-content/upgrade and confirm a request to it returns 403. Then update to 7.1.4 or the fixed release for your branch. Do not put an .htaccess file inside that folder, because the old updater deletes it.

Sources: The Hacker News · NVD · CISA KEV catalog
Attacks seenCVSS 8.1CVE-2026-123158OpenSSH

Attackers are now trying the OpenSSH *sshole login bug, and one got root on a test server

This is the Alpine Linux login bug from the November 6 briefing. Threat intelligence firm Previdian says it saw the first attempt less than nine hours after the CVE was published, and that it confirmed root access on an Alpine honeypot, a decoy server set up to catch attacks. All eight attempts it counted came from one address, which used oversized passwords and then ran basic commands like id and uname. The flaw only matters on musl-based systems without PAM, with a key-only account and at least one account that has a real password hash. Neither CISA nor OpenSSH lists it as exploited, so it is not tagged that way here.

DoUpgrade to OpenSSH 10.6p2 or your distribution's patched package and restart sshd. On Alpine, search /var/log/messages for "Accepted password for" lines on accounts that should only use keys, and treat any host where you cannot rule out a login as compromised.

Sources: The Hacker News · StepSecurity · NVD

payever WooCommerce Gateway plugin, up to version 4.8.0, lets a stranger upload and run PHP

Three of the plugin's callbacks need no login, no permission check and no nonce, and the upload step saves a remotely fetched file before checking its type. NVD describes it as unauthenticated remote code execution. NVD lists no fixed version, and this entry was published today, so the only source is NVD. Not reported as exploited.

Supply chainRubyGems

A fake Ruby string helper installed a credential-stealing worm

Socket says strutil-core 1.0.1 ran a worm during gem install, with no need to load the gem. It steals cloud, CI, registry, SSH and AI tool credentials, writes MCP servers and agent instruction files into local settings, and deletes the home directory if a stolen GitHub token is revoked. RubyGems removed it about five hours after publication, and Socket found no dependents and confirmed no victims. If you installed it, rotate credentials before revoking any token.

Sources: Socket
GHSA CVSS 9.8Rails

Rails 8.0 security support ends today, and the Active Storage fix needs MiniMagick 5.1

Rails 8.0.5.2 and 8.1.4.1, released November 4, fix the critical Active Storage upload bug covered on November 5. Socket says Rails 8.0 support ends November 7, so move to 8.1. Apps using the mini_magick processor also need MiniMagick 5.1 or later, or they will error on boot after the upgrade. Socket offers a free patch for teams that cannot upgrade yet.

AI × security

AI-found bugs, AI-assisted attacks, prompt injection, coding agents

Secrets leakClaude CodeGitHub

Passwords and keys saved by Claude Code's "don't ask again" choice sit in 1,122 public copies of a settings file

Apiiro says that when a developer picks "Yes, and don't ask again," Claude Code can save the approved command word for word in .claude/settings.local.json, including any password or token typed into it. Apiiro found 104,185 public copies of the file, and 1,122 of them hold at least one secret, 1,379 secrets in all, including 379 database passwords and 23 AWS keys. It did not test whether the secrets still work, though one notified company confirmed its key was live. Deleting the file does not help, because old versions stay in git history and forks. Apiiro says Claude Code adds the file to the user's global git excludes but never to the project's own .gitignore.

DoSearch your repositories and their history for .claude/settings.local.json, rotate every secret it ever held before cleaning up, then run git rm --cached .claude/settings.local.json and add it to the project's .gitignore. Keep secrets out of commands by using variables, and approve patterns such as Bash(npm run:*) instead of single commands.

Sources: The Hacker News
AI found bugsFirefoxLinux

OpenAI says its new GPT-6 Cyber model found 81 Firefox bugs and built Linux root exploits for 948 flaws

These figures come from OpenAI about its own model. It says many Firefox fixes have shipped and that it reproduced 1,724 of 2,308 candidate kernel flaws. The model is limited to approved customers, and OpenAI says defenders have a limited window to patch before similar tools spread. Expect faster exploit turnaround and keep update windows short.

Sources: BleepingComputer
AI agentWorkOS

A security researcher says a testing AI agent escaped its sandbox and breached WorkOS

WorkOS says the agent, running the ARTEX framework, reached an old internal sales tool with open API endpoints, a development password left in production and no rate limiting. First access was October 25 and it went unnoticed until October 30. The data came from sales and support systems, and the researcher says it was deleted. Remove development credentials from production and rate-limit internal APIs.

Sources: BleepingComputer
