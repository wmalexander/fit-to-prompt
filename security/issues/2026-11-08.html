01

Patch now

Confirmed exploited or critical and easy to reach

ExploitedCVSS 7.5CVE-2026-19868SonicWall

SonicWall firewall VPN bug lets attackers skip two-step login, and SonicWall says it may be exploited

The bug is in the SSL VPN part of SonicOS, the system that runs SonicWall firewalls. Someone who holds a valid login for a different sign-in method can get past SAML login, including a two-step (MFA) check that SAML enforces. SonicWall says the VPN is only exposed if SAML login is turned on. Affected are Gen7 TZ, NSa, NSsp and NSv firewalls on SonicOS 7.3.3-7015 or older, and Gen8 TZ, NSa and NSv firewalls on 8.2.2-8015 or older. SonicWall says it investigated a report of possible exploitation, and CISA added the bug to its exploited list on November 6 with a federal deadline of November 20. Neither has shared details of the attacks. SonicWall rates the bug 7.1, while NVD currently lists 7.5.

DoUpgrade to SonicOS 7.3.4-7013 or 8.2.3-8015, because SonicWall lists no workaround. If SAML login is on and you cannot patch today, review recent VPN sign-ins for accounts that used a different method than SAML.

Sources: SecurityWeek · NVD · CISA KEV catalog
02

WordPress & PHP watch

Core, plugins, themes, PHP and the frameworks on top of it

CVSS 9.1CVE-2026-118066WordPress

LatePoint booking plugin, up to 5.7.6, lets a stranger take over accounts

NVD says the plugin builds part of a database query from request values without binding them, so an unauthenticated visitor can abuse the password reset step to take over an account. The plugin's WordPress.org page lists 5.7.8 as the current release, last updated November 3, and about 1.8 million downloads overall. NVD's analysis is still deferred, and it is not reported as exploited.

DoUpdate LatePoint to 5.7.8 or later, and review recently reset passwords on booking accounts.

Sources: WordPress.org plugin page · NVD
CVSS 9.8CVE-2026-104014WooCommerce

Email OTP Verification for WooCommerce, up to 2.1.0, lets anyone finish a password reset

The reset step only checks that an email is marked "verified" in the database, with no time limit or per-reset token, so an abandoned reset can be finished by someone else. NVD lists no fixed version, and the only source is NVD. Not reported as exploited. Deactivate it if you can.

CVSS 9.8CVE-2026-119075WooCommerce

Registration Form for WooCommerce, up to 1.1.4, lets a buyer pick their own user role

The checkout path accepts a role value from the request without checking it against the allowed roles, so a new customer could register as an administrator. NVD lists no fixed version, and the only source is NVD. Not reported as exploited. Deactivate it if you do not need the role field.

CVSS 9.0CVE-2026-121491WordPress

Fiber Admin before 4.0.1 can run attacker code if its custom database error page is on

A request header is written into a PHP file without cleaning, and an attacker has to win a timing race against an administrator saving settings. The plugin's WordPress.org page lists 4.0.1 as current. It has a small install base, so check only if you use it. Not reported as exploited.

04

Web stack & supply chain

npm, Composer, PyPI, browsers, CI, hosting

CVSS 9.1CVE-2026-120984Keycloak

Keycloak lets a user with client management rights run JavaScript on the server

If a client is created or imported with authorization services on, a leftover session value lets an attacker with client management permission upload a malicious policy that runs when an authorization request comes in. NVD lists no fixed version and its analysis is pending, so the only source is NVD. Not reported as exploited. Limit who holds client management rights until a fixed release appears.

CVSS 9.3CVE-2026-123614imgproxy

imgproxy 4.0.0 to 4.0.15 can be crashed or possibly taken over with a crafted ICO image

A size value in the ICO image loader wraps around and corrupts memory, which can crash the process or run code. NVD says versions before 4.0.16 are affected, and the only source is NVD. Upgrade to 4.0.16, or stop accepting ICO files if you cannot. Not reported as exploited.

  • Check your sites for Email OTP Verification for WooCommerce and Registration Form for WooCommerce, and deactivate them if you can.
