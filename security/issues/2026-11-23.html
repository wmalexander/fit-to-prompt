ExploitedCVSS 9.8 (v3.1)CVE-2026-76466Cisco Expressway

Cisco Expressway bug that gives root access is now being exploited

Cisco Expressway-C and Expressway-E, the gear that links company voice and video systems to the internet, can be taken over by an outsider on a clustered setup. The bug comes from reused cookies and missing client certificate checks on the database service. CISA added it to its Known Exploited Vulnerabilities list on November 20. Cisco's own advisory said in October that it knew of no attacks, so the exploitation report comes from CISA. The Russian security firm F6 reported that attackers used an AI assistant to exploit it, then moved from two internet-facing devices to two more cluster nodes inside the network. Most web teams do not run Expressway, but it often sits next to the same networks your servers live on.

DoInstall the fixed Expressway software Cisco released in October (check Cisco's advisory for the build for your release line), then look for unexpected root-level activity on any cluster nodes.

Sources: BleepingComputer · NVD
CVSS 9.2 (v4.0)CVE-2026-134815npmNo attacks reported

simple-git lets a crafted argument run commands on your server

simple-git, which gets about 15 million downloads a week, has a guard that blocks dangerous git options. A new flaw lets the --exec option slip past that guard on read operations such as listRemote() and raw(). It only matters if your code lets outside input reach those calls, for example a repository URL or option typed by a user. The score comes from NVD's record, which has not been fully reviewed yet.

DoUpdate simple-git to 4.1.0 or later, and stop passing user-supplied values straight into git arguments.

Sources: GitHub advisory · simple-git 4.1.0 release · NVD

CVSS 9.8 (v3.1)CVE-2026-131782WordPressNo attacks reported

Simple Shopping Cart could be tricked into loading attacker-chosen code

The plugin (10,000+ sites) trusted saved cart data too much, which allows PHP object injection in versions through 5.3.3. Whether that leads to full takeover depends on what other code is on the site. The 5.3.4 changelog credits Patchstack with the report.

DoUpdate Simple Shopping Cart to 5.3.4.

Sources: Plugin changelog · NVD
CVSS 9.8 (v3.1)CVE-2026-131754WordPressNo attacks reported

APCu Manager has an object injection bug through version 4.6.1

The plugin (10,000+ sites) has the same kind of untrusted-data bug as the cart plugin above. The newest release is 4.7.0, which is past the affected range, but I could not confirm from its changelog that this bug is the one it fixed.

DoUpdate APCu Manager to 4.7.0 or later, or deactivate it if you do not use it.

Sources: Plugin page · NVD
CVSS 6.9 (v4.0)CVE-2026-134748CVE-2026-134750CVE-2026-134751WordPressNo attacks reported

Members plugin leaks content it is supposed to keep private

Members (300,000+ sites) had three gaps where a visitor who is not logged in could read protected material. Private Site mode could be bypassed through the login page path (3.2.28 before 3.3.2). The Latest Comments block exposed comments on restricted posts, and the Latest Posts block in full-content mode exposed whole restricted posts (both before 3.3.1). Version 3.3.1 also now requires PHP 8.0.

DoUpdate Members to 3.3.2, and confirm your hosting runs PHP 8.0 or newer first.

Sources: Plugin changelog · NVD · NVD · NVD

CVSS 9.2 (v4.0)CVE-2026-134814npm

binary-parser can run JavaScript from crafted parser settings

Versions before 2.3.1 run code if attacker-controlled text reaches certain parser options. Normal use with fixed definitions is not affected. Update to 2.3.1. NVD

CVSS 8.7 (v4.0)CVE-2026-134812npm

msgpackr can be slowed to a stop by trickled data

Versions before 2.1.4 spend more and more time re-reading an incomplete stream, which blocks the Node.js event loop. Update to 2.1.4 if you decode untrusted streams.

BreachE-commerce

Cleverbridge says stolen card data included security codes

The checkout and subscription platform says it found the intrusion on November 4 and began notifying customers on November 20. Card numbers, expiry dates and CVV codes were taken. It has not said how the attackers got in or how many people were hit. If your site sells through Cleverbridge, ask them whether your customers are affected.

ExploitedRouters and KVMs

GL.iNet cloud flaw used to install malware on routers and KVMs

GL.iNet says an outsider used a hole in its cloud management service to infect devices, and it has closed that path. Devices already infected stay infected. Because KVMs control attached computers, anyone using one to reach a server should check it. Install the latest firmware (KVMs 1.10.3 or later for most models) and reset infected devices without restoring old settings, per BleepingComputer.

AI × security

AI-found bugs, AI-assisted attacks, prompt injection, coding agents

Worth readingAI-assisted attacks

India's CERT-In: AI tools are speeding up attacks and abusing payment approvals

CERT-In reports unauthorized payments at banks and fintech firms where attackers changed business records and approval relationships, then let legitimate payment systems do the rest. It also describes attacker tooling that scans for exposed systems, writes exploits from patch details and runs many AI agents in parallel. Its figure that the time from first access to damage shrank from days to hours comes from CERT-In's own reporting. The practical lesson for developers is to review who can change payout and approval data, and to add checks that do not depend on the same system.

Today's checklist

  • Install the October Expressway fix from Cisco, or confirm you do not run Expressway clusters.
  • Update simple-git to 4.1.0 and search your code for user input reaching listRemote() or raw().
  • Update the Members, Simple Shopping Cart and APCu Manager plugins on every WordPress site you run.
  • Update binary-parser to 2.3.1 and msgpackr to 2.1.4 where you use them.
  • If you sell through Cleverbridge, ask them whether your customers' cards were involved.
